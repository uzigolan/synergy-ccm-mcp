# Local Manual Harvests

**Contents:** [Purpose](#purpose) · [Ownership](#ownership) · [What to commit](#what-to-commit)

## Purpose

This directory is the local landing area for harvested or extracted manual content that feeds the Synergy knowledge corpus.

## Ownership

IBM Rational Synergy documentation belongs to IBM. Harvested IBM Docs pages and extracted IBM manual text must retain their IBM source URL, product version and provenance in corpus frontmatter or manifests.

## What to commit

Do not commit third-party manual text unless the applicable license or entitlement explicitly permits redistribution. Keep local harvested IBM/manual subdirectories here for indexing and testing, and commit only source checklists, ingest code, manifests without copyrighted body text, or project-authored notes.
