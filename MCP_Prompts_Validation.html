9. Attribute Schema Discovery ⚠ Timeout Error

List all queryable attributes for CR (problem) objects

svetlana, what fields can I filter CRs on?
MCP Tool: list_attributes(database="prod-core", cvtype="problem")
⚠ Error: Command timed out after 120s
Command: ccm query cvtype='problem' -u -ns -f %objectname
Root Cause: The problem cvtype has ~47,000 objects in this database. Sampling the first one requires listing all objects with cvtype filter.

Workaround & Solution:

✓ Documented Error: The timeout is expected for large databases. Users should reference the CR field reference table in synergy-change-requests skill instead.

Known Queryable CR Fields:
  • problem_number, crstatus, severity, priority, product_name
  • component, subsystem, found_at_site, phase_found, phase_fixed
  • submitter_name, resolver, in_verification_by
  • entry_date, resolution_date, conclusion_date, release
  • problem_synopsis, request_type

Better Alternative Approach:

Use the DEFAULT_CR_FIELDS constant in synergy-change-requests skill or reference the object_attributes tool:

Better MCP Tool: object_attributes(database="prod-core", objectname="problem1~1:problem:IL") — samples a single CR

✅ What's Now Possible:

  • ✓ Single-call aggregation: group_by returns per-key counts instead of fetching all rows
  • ✓ Pagination: offset parameter for stepping through large result sets
  • ✓ CR workflows: find_crs, cr_info, cr_tasks tools for problem-driven analysis
  • ✓ Bulk object lookup: task_objects_bulk processes 1-100 tasks in one call with file frequency rollup
  • ✓ Date parsing: normalizes "H1 2026", "2026-02-01", "1/2/2026", "last 6 months" → time() format
  • ✓ Wildcard release matching: release_match="etxa*" instead of raw match operator
  • ✓ CSV/TSV export: format="csv"|"tsv" on any finder tool
  • ✓ Release discovery: find_releases(pattern) lists all releases matching a name pattern

⚠️ Known Limitations:

  • ⚠ list_attributes timeout: Databases with >30K objects of a type may timeout. Workaround: use skill reference docs or query a single object with object_attributes
  • ⚠ Severity filter case-sensitive: Use "Critical", "Major", "Minor", "Normal" exactly (not "high", "medium")
  • ⚠ Instance suffix required: Multi-database sites need IL!n or other DB prefix in task IDs for task_objects_bulk
